# PrivGPT Studio 🛡️🤖

> **Private, local-first LLM orchestration platform and document intelligence workspace.**

PrivGPT Studio allows developers and privacy-conscious users to interact with local LLMs, analyze confidential documents, and execute retrieval-augmented generation (RAG) completely on-device without exposing data to third-party cloud APIs.

---

## ✨ Key Features

- 🔒 **100% On-Device Execution**: Zero telemetry or cloud dependencies for local models.
- ⚡ **Document Intelligence & RAG**: Vector-indexed document parsing for PDFs, Markdown, and TXT.
- 🎯 **Multi-Model Orchestration**: Seamlessly swap between WebLLM, Ollama, and local ONNX runtimes.
- 📊 **Streaming Chat UI**: Real-time response streaming with syntax highlighting and code block copying.

---

## 🛠️ Tech Stack

- **Framework**: Next.js (App Router), React, TypeScript
- **Styling**: Tailwind CSS, Radix UI Primitives, Lucide Icons
- **Local AI Engine**: WebLLM, Transformers.js, Vector DB Embeddings
- **Deployment**: Vercel / Docker
